R+3) › Suivant ; ② le niveau au-dessus est proposé, ajoutez R+5, R+6… ou « Tous les niveaux » ; ③ calage à l'équerre une seule fois par plan, sur les mêmes fils (enregistré dans le plan, plus besoin de recommencer) ; ④ passez d'une paire à l'autre avec ‹ › (R+3→R+4→R+5…)

- **Briefing** : nouvelle carte « Changements entre niveaux » pour ceux qui ne sont pas encore vus
