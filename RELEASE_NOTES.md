## Nouveautés — AutoCAD DWG sur le téléphone
- Import direct des fichiers **.dwg** (Plans › + › Importer) : le plan s'affiche comme un PDF, avec pins, indices et lots ; le DWG d'origine est gardé
- **Tracer en PDF vectoriel** (comme le « Tracer » d'AutoCAD) : format A4 → A0, orientation, échelle (ajuster ou 1/50, 1/100…), couleurs (noir, couleurs, gris), épaisseurs (du dessin, par couleur type CTB, uniforme), calques à masquer, une page par cadre/cartouche détecté, aperçu en direct
- **DWG → DXF** : export et partage
- **Fusionner** plusieurs plans (PDF, DWG, images) en un seul PDF, dans l'ordre choisi
- **Diviser** un PDF : une page par fichier ou par plages (1-3, 4, 5-8)
- Chaque PDF créé : Partager, ou Ajouter aux plans dans le niveau choisi
- Menu ⋮ d'un plan : Tracer en PDF, Exporter DXF, Partager le DWG / PDF d'origine, Diviser ce PDF
