# Pages publiques SiteTeam (GitHub Pages › /siteteam/)

- `confidentialite.html`, `suppression-compte.html`, `conditions.html`, `index.html` : pages demandées par Google Play.
- `contact.txt` : l'adresse e-mail de contact (une ligne). Tant qu'elle vaut `A_COMPLETER`, les pages légales ne sont **pas** publiées.
- Publié par `.github/workflows/siteteam-web.yml` avec le panneau d'administration (`admin.html`).
